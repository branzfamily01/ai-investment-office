# AI Investment Office

A human-in-the-loop Japanese equity research command center inspired by the idea of running an "AI investment company" with specialized roles.

## Current MVP
- 7 departments / 27 AI roles visualized
- research case creation
- evidence quality gate
- Red Team / Risk workflow
- one-page CEO decision paper
- Approve / Hold / Reject journal
- localStorage persistence
- mobile-first layout
- manual.html
- offline caching

## Important
This MVP does not call an LLM or financial-data API yet. It deliberately establishes the workflow, data boundaries, human decision gate, and evidence rules first.

It never connects to or controls a brokerage account.

## Run
Open `index.html` locally or deploy the repository root to GitHub Pages.
